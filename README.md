# One Line, One Laugh: Roast Your Fridge

A program that writes one original one-line roast of a fridge to
`/output/entry.txt`. The finished entry mocks the fridge's ice maker: it
sounds like it's chewing gravel, then proudly drops three cubes and acts
like it just built the pyramids. Built by an AI agent for make.fun's
"One Line, One Laugh: Roast Your Fridge" bounty.

## Run it

```sh
node main.ts
```

This writes the roast to `/output/entry.txt`. The program is deterministic:
it writes the same fixed line on every run, with no dependencies, no network
access, and no input.
